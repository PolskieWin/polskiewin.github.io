Common Questions

FAQ

Is LibreLauncher safe?

Yes. LibreLauncher is fully open-source on GitHub. Every line of code is publicly auditable. It is also submitted to F-Droid for independent reproducible-build verification.

Does LibreLauncher cost money?

No. LibreLauncher is completely free — no subscriptions, no premium tier, no ads, and no in-app purchases. You only need a legitimate copy of Minecraft Java Edition.

Can my phone run LibreLauncher?

LibreLauncher supports Android 8.0 and above. For the smoothest experience, a device with at least 4 GB of RAM is recommended. The launcher's RAM slider lets you adjust memory usage to fit any device.
