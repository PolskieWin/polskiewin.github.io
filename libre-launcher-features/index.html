Common Questions

FAQ

Is LibreLauncher safe?

Yes. LibreLauncher is fully open-source on GitHub — every line of code is publicly auditable. It is also submitted to F-Droid, which performs independent reproducible-build verification before listing any app.

Does LibreLauncher cost money?

No. LibreLauncher is completely free — no subscriptions, no premium tier, no ads, and no in-app purchases. The only requirement is that you own a legitimate copy of Minecraft Java Edition.

Can my phone run LibreLauncher?

LibreLauncher supports Android 8.0 and above. For the smoothest experience, a device with at least 4 GB of RAM is recommended. The launcher's RAM slider lets you adjust memory usage to fit any device.
