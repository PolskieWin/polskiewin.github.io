How to Play Minecraft Java on Android (Step-by-Step)

5 minutes Android 8.0+ Free Microsoft Account Required Updated 2026

This guide walks you through every step to run full Minecraft Java Edition on your Android phone using LibreLauncher, a free open-source launcher. No emulators, no lag tricks — just the real game.

Installation Guide

5 Steps to Minecraft Java on Android

1

Download LibreLauncher from GitHub

Open your browser and go to the LibreLauncher GitHub Releases page. Tap the latest .apk file to start the download directly on your phone.

Tip: Download directly onto your phone — no PC required.
Go to GitHub Releases
2

Install the APK on Your Android Device

Open the downloaded .apk file from your notifications or file manager. Android will ask you to allow installation from unknown sources.

How to allow: Go to Settings → Apps → Special app access → Install unknown apps, find your browser, and enable it. You can disable this again after installing.
3

Log In with Your Microsoft Account

Open LibreLauncher. Tap Log In and sign in with the Microsoft account linked to your purchased copy of Minecraft Java Edition.

Note: You must own Minecraft Java Edition. LibreLauncher does not provide or pirate the game.
4

Allocate RAM and Select Your Minecraft Version

In the launcher settings, choose how much RAM to allocate. 2–3 GB works well for most devices. Then pick the Minecraft Java version you want to play, or add Fabric or Forge.

Performance tip: Avoid allocating more than 70% of your device's total RAM to prevent system stutters.
5

Hit Play

Tap the Play button. LibreLauncher will download the game assets on first launch, then start Minecraft Java Edition. That is it — you are in.

First launch: Asset download may take a few minutes depending on your connection. Subsequent launches are instant.

Pro Tips

Tips for the Best Experience

Use a controller. Bluetooth gamepads work great for Minecraft Java on Android.

Install Sodium or OptiFine. These performance mods dramatically improve FPS.

Enable Wi-Fi. A stable network connection prevents lag when playing multiplayer.

Keep LibreLauncher updated. Check GitHub Releases regularly for performance and stability improvements.
