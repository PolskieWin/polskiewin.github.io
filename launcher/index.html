Libre Launcher (Android)

Lightweight, open-source Minecraft: Java Edition launcher built natively for Android devices

Libre Launcher (Android) is an open-source Minecraft: Java Edition launcher for Android (arm64-v8a), developed by PolskieWin. Built with sub-millisecond native Rust controls (libre_controls), the LibreMobile Vulkan renderer, bundled Java 21 & Java 25 runtimes, full Modrinth mod/shader integration, and a lean 31 MB stripped APK footprint with zero tracking or telemetry.

Important Disambiguation: Android Mobile Launcher (Not PC) Libre Launcher by PolskieWin is engineered specifically and exclusively for Android mobile platforms (arm64-v8a). It is an independent mobile application and is completely separate from legacy desktop PC launchers or multi-platform desktop clients that share the "LibreLauncher" name. On Android, Libre Launcher delivers native mobile touch controls, Turnip/Zink driver management, and battery-efficient AFK hibernate.

Engineered Specifically for Android Hardware

Native Rust Touch Controls

Compiled from libre_controls with exponential moving average (EMA) aim smoothing, sub-millisecond touch event dispatch, 1:1 dynamic coordinates, and zero ghost clicks.

Upgraded Mod Scanner (v3.70)

Pre-boot scanner rewritten with robust native JSON parsing, accurately reading fabric.mod.json, neoforge.mods.toml, and Quilt metadata before VM initialization.

LibreMobile Vulkan Renderer

Custom driver integration enabling direct runtime loading of Turnip, Freedreno, and Mesa Zink drivers with unlocked 120Hz/144Hz display mode negotiation and zero UI caps.

Bundled Java 21 & Java 25

Includes custom stripped OpenJDK 21 and OpenJDK 25 runtime environments featuring Android 16 (API 36) linker namespace isolation patches.

Modrinth Ecosystem Integration

Native in-launcher searching, downloading, and version resolution for Fabric, Quilt, NeoForge, and Forge mods, shaders, and resource packs.

F-Droid Source Compliance

100% compliant with F-Droid inclusion requirements: all shared libraries including FreeType are built strictly from source submodules without proprietary blobs.

Frequently Asked Questions

What is Libre Launcher?

Libre Launcher is an open-source, mobile-first Minecraft: Java Edition launcher created specifically for Android (arm64-v8a) devices by PolskieWin. It features sub-2ms Rust touch controls, mobile Turnip driver loading, and bundled OpenJDK 21/25 runtimes.

Is Libre Launcher for Android or PC?

Libre Launcher by PolskieWin is engineered strictly for Android smartphones, tablets, and handheld devices. It is an independent mobile project distinct from legacy desktop PC launchers sharing the name.

How do I download Libre Launcher on Android?

You can download official signed APKs from GitHub Releases (v3.70), GitLab Releases (v3.70), or install through Obtainium for automatic updates. It is also submitted to F-Droid under MR !58168.

Does Libre Launcher support mods on Android?

Yes! Version 3.70 resolves mod detection and loading bugs with an upgraded native JSON mod scanner supporting Fabric, NeoForge, Quilt, and Forge modpacks directly on Android.

Is Libre Launcher moving away from PojavLauncher and rewriting in Rust?

Yes. Libre Launcher is executing an active Hybrid Tiny Rewrite. We are progressively porting performance-critical subsystems—such as touch input (libre_controls), mod/file scanning, cache validation, and native runtime bindings—into pure Rust, while systematically transitioning away from the legacy PojavLauncher architecture to achieve ~15s cold boot times, a leaner ~16 MB stripped APK target, and direct Vulkan/Turnip driver reliability.
