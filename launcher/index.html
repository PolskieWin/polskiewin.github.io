Libre Launcher (Android)

Lightweight, open-source Minecraft: Java Edition launcher for Android

Libre Launcher (Android) is a lightweight, open-source Minecraft: Java Edition launcher for Android (arm64-v8a), developed by PolskieWin. Built with native Rust controls, the LibreMobile renderer, bundled Java 21 & Java 25 runtimes in a 31 MB stripped APK (no bundled runtime), Modrinth mod/shader integration, and Material You home-screen widgets.

Distinction from Desktop PC Launchers Libre Launcher (Android) is specifically engineered and optimized for Android mobile devices (arm64-v8a). It is an independent project developed by PolskieWin and is completely unrelated to desktop PC launchers or multi-platform desktop clients that share the "LibreLauncher" name.

Engineered for Android Hardware

Native Rust Touch Controls

Compiled from libre_controls with exponential moving average (EMA) aim smoothing, sub-millisecond touch event dispatch, 1:1 dynamic coordinates, and zero ghost clicks.

LibreMobile Vulkan Renderer

Custom driver integration enabling direct runtime loading of Turnip, Freedreno, and Mesa Zink drivers with unlocked 120Hz/144Hz display mode negotiation and zero UI caps.

Bundled Java 21 & Java 25

Includes custom stripped OpenJDK 21 and OpenJDK 25 runtime environments featuring Android 16 (API 36) linker namespace isolation patches, compressed into a lean 31 MB stripped APK (no bundled runtime).

Modrinth Ecosystem Integration

Native in-launcher searching, downloading, and version resolution for Fabric, Quilt, NeoForge, and Forge mods, shaders, and resource packs.

F-Droid Source Compliance

100% compliant with F-Droid inclusion requirements: all shared libraries including FreeType are built strictly from source submodules without proprietary blobs.

Zero Telemetry & Private

No user tracking, no analytics, no external pingbacks, and no background profiling. Your credentials and gaming data remain exclusively on your device.
